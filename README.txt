CHANDANA'S BIRTHDAY SURPRISE
=============================

Included: index.html, style.css, script.js and an empty books/ folder.

The uploaded PDFs appear to be unauthorised copies of copyrighted books. I have
not included or repackaged those full books in this website. Only add PDFs you
have permission to distribute, or link to authorised ebook/library sources.

For authorised PDFs, put files in books/ using these exact names:
sabotage.pdf
madness.pdf
the-sacrifice.pdf
carnage.pdf
the-sinner.pdf
chaotic.pdf
lights-out.pdf
the-ritual.pdf

The corresponding button automatically changes to "Read book" when the file
exists and the website is served over HTTP/HTTPS.

Preview locally:
  python -m http.server 8000
Then open http://localhost:8000

Publish using GitHub Pages:
1. Create a GitHub repository and upload the website files.
2. Open Settings > Pages.
3. Select Deploy from a branch, choose main and /(root), then Save.
4. Send the resulting Pages link to Chandana.

The website is public. Do not upload private or unauthorised material.
